|----------|-------------|
| webview → host | untrusted Intent messages |
| user-picked file → resolveTour | arbitrary JSON path from the "A saved tour file…" picker |
| tour base/head refs → git | ref strings from LLM-written JSON passed to git |
| serializer state → open | webview-persisted {id,path} after reload |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-09 | Tampering | TourPanel.onDidReceiveMessage | mitigate | parseIntent on every message; undefined → ignored; gotoStep command checks Number.isInteger |
| T-05-10 | Tampering / injection | resolveTour git calls | mitigate | execFile via git() (no shell); refs empty or starting with '-' skipped; failures leave SHAs '' |
| T-05-11 | Tampering | serializer restore | mitigate | state must be an object with a string path that exists; otherwise the panel is disposed; the file still goes through loadTour |
| T-05-12 | Elevation | webview options | mitigate | localResourceRoots limited to dist/webview and media; CSP from webviewHtml with per-load nonce |
| T-05-13 | Information disclosure | notes in workspaceState | accept | Local VS Code storage only, never written to the repo (DOC-05) |
