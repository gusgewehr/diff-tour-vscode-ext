<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extension/harness -> tour.exe argv | Ref names and paths arrive as argv, never through a shell |
| tour.exe -> claude child | LLM process runs with read-only tools inside the export dir |
| LLM reply -> tour JSON | Untrusted model output becomes the cached tour |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03 | Tampering | ref argument injection | mitigate | headless reuses resolve()+RevParse; git is run via exec with args (no shell); harness uses spawn with shell:false |
| T-01-04 | Denial of Service | orphaned claude after cancel/kill | mitigate | cmd.Cancel -> taskkill /T /F; WaitDelay 10s; kill-on-close Job Object for hard kills of tour.exe |
| T-01-05 | Tampering | invalid or malicious LLM JSON | mitigate | unchanged upstream parse: DisallowUnknownFields, Validate(), render.Check(), max 2 repairs; invalid -> error invalid_tour, nothing cached |
| T-01-06 | Information Disclosure | stale export dirs (copies of repo source) left in %LocalAppData% | mitigate | deferred ws.Remove() on cancel; 1-hour stale sweep at each --json run |
| T-01-07 | Spoofing | stdout corrupted by stray human text | mitigate | all human text to stderr; only the mutex-guarded encoder writes stdout |
</threat_model>
