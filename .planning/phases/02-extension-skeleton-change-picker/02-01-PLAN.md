- `git(cwd, args)`: `child_process.execFile('git', ['-c', 'core.quotepath=false', ...args], { cwd, maxBuffer: 16 * 1024 * 1024, windowsHide: true })`, never a shell (per D). Resolve stdout as a string; reject with an Error whose message is git's trimmed stderr (fall back to the error message).

- `currentBranch`: `git symbolic-ref --short -q HEAD`, undefined when detached (non-zero exit).
- `uncommittedCount`: number of non-empty lines in `git status --porcelain`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo -> git process | Repo config and ref names come from the opened repository |
| user input -> git args | Range text and settings flow into git argv |
| gh output -> extension | PR JSON from gh is parsed and used in a fetch refspec |
| cache dir -> extension | *.meta.json files are parsed |
| npm registry -> dev machine | devDependencies installed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation | git in untrusted repo (core.fsmonitor etc.) | mitigate | `capabilities.untrustedWorkspaces.supported: false` in package.json so the extension never runs in Restricted Mode |
| T-02-02 | Elevation | difftour.cliPath from workspace settings | mitigate | `scope: machine` on difftour.cliPath |
| T-02-03 | Tampering | refs passed to git (option injection) | mitigate | execFile argv only, no shell; resolveTarget and parseRange reject refs starting with `-` |
| T-02-04 | Tampering | gh PR number in `pull/<n>/head` | mitigate | Only positive integer `number` values accepted |
| T-02-05 | Denial of service | huge git output | mitigate | maxBuffer 16 MB; gh timeout 15 s |
| T-02-06 | Tampering | malformed *.meta.json | mitigate | JSON.parse in try/catch, only string label / numeric files read |
| T-02-SC | Tampering | npm installs | mitigate | Only typescript, esbuild, @types/vscode, @types/node, @vscode/vsce; names, versions and repos (microsoft/TypeScript, evanw/esbuild, DefinitelyTyped, Microsoft/vsce) verified with `npm view` during planning; package-lock.json committed |
