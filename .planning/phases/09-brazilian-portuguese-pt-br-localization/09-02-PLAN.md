Design choice (Claude's discretion within CONTEXT "have them take a translate function t (default identity)"): instead of threading a `t` parameter through every pure function signature, pure modules import one injectable translator from `src/l10n.ts`. It has no `vscode` import, defaults to English formatting, and extension.ts injects `vscode.l10n.t` at activation. Node tests never call setTranslator, so they keep seeing English.

src/l10n.ts (NEW, contract):
- `export type Translate = (message: string, ...args: Array<string | number | boolean>) => string`
- `export function format(message, ...args)`: replaces `{N}` with `String(args[N])`; leaves `{N}` untouched when args[N] is undefined (same as vscode.l10n.t)
- `export function t(message, ...args)`: delegates to the current impl (default `format`)
- `export function setTranslator(fn: Translate, lang: string): void`
- `export function displayLanguage(): string` (default 'en'; used by plan 09-03 for `<html lang>`)

Module rules (CONTEXT): vscode-aware files (import 'vscode': extension.ts, pick.ts, cli/startTour.ts, small/smallChange.ts, tour/controller.ts, tour/openCode.ts, views/changesTree.ts, views/outlineTree.ts) call `vscode.l10n.t('English {0}', arg)` directly. Pure files loaded by node tests (cli/errors.ts, cli/detect.ts, cli/progress.ts, small/logic.ts, git/changes.ts, tour/openPlan.ts, tour/enrich.ts) import `{ t } from '../l10n'` and NEVER import vscode.

Placeholders: use `{0}`, `{1}` in a single-quoted literal; never a template literal inside t(). Example: `` `Writing tour: ${target.label}` `` becomes `vscode.l10n.t('Writing tour: {0}', target.label)`.

Button labels: `ErrorAction` in src/cli/errors.ts stays the English union used as an id. At the showErrorMessage/showInformationMessage call sites (startTour.ts `info.actions`, 'Open tour'; pick.ts 'Open Settings', 'How to install'; smallChange.ts 'Open Settings'), build the translated label with a literal `vscode.l10n.t('Open Settings')` etc., show the labels, and compare the returned choice against the same translated label variable (not the English literal).
