## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extension -> CLI process | target refs and settings become argv |
| CLI result -> file system | done.path is copied into globalStorage |
| error text -> UI | CLI/LLM messages shown in notifications and the OutputChannel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-09 | Tampering | startTour spawn | mitigate | all spawning through runner.run (shell: false, args array); cli path from detectTools |
| T-04-10 | Tampering | saveTour copy of done.path | accept | path comes from our own fork's stdout; destination name is the hex key under globalStorage, so nothing outside storage is written |
| T-04-11 | Denial of service | concurrent runs | mitigate | one run at a time (module `current`); a second request reveals the running panel |
| T-04-12 | Information disclosure | error notifications | accept | notifications show CLI messages only; problems and stderr go to the local OutputChannel, nothing leaves the machine |
| T-04-13 | Elevation | untrusted workspaces | mitigate | package.json already declares untrustedWorkspaces supported: false, so the CLI never runs in restricted mode |
</threat_model>
